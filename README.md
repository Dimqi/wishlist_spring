# Wishlist - Сервис для создания и обмена списками желаний

**Wishlist** - веб-сервис, который позволяет пользователям создавать персонализированные списки желаний, делиться ими с друзьями и семьёй через публичные ссылки, а также бронировать подарки, сохраняя сюрприз для владельца списка.

## Основные возможности

**Создание вишлистов** - добавить желания с названием, ссылкой и приоритетом  
**Теги** - возможность добавить к желанию тег, например "Новый год", "День рождения" и т.д.  
**Публичные ссылки** - возможность делиться списком через уникальную ссылку  
**Бронирование подарков** - гости могут бронировать подарки, чтобы избежать дублирования, либо договариваться о совместном подарке  
**Секретность** - владелец списка не видит, кто забронировал подарок  
**Кэширование** - данные кэшируются через Redis для быстрого доступа  
**Безопасность** - JWT-аутентификация, защита от подбора ID  


## API Эндпоинты  
| Метод | Эндпоинт | Описание | Параметры  

### Аутентификация  
| POST | `/api/auth/register` | Регистрация нового пользователя | AuthRequestDTO (body)  
| POST | `/api/auth/login` | Вход в систему (возвращает JWT) | AuthRequestDTO (body)  

### Желания  
| GET | `/api/wishes/all` | Получить все желания пользователя | - |  
| GET | `/api/wishes/{id}` | Получить желание по ID | `id` (path) |  
| POST | `/api/wishes` | Создать желание | `WishRequestDTO` (body) |  
| DELETE | `/api/wishes/{id}` | Удалить желание | `id` (path) |  
| PATCH | `/api/wishes/reserveWish` | Забронировать подарок | `token` (query), `wish_id` (query) |  
| DELETE | `/api/wishes/unReserveWish` | Отменить бронирование | `wish_id` (query) |  
| GET | `/api/wishes/AllByTag` | Получить желания по тегу | `tagName` (query) |  

### Публичный шеринг  
| GET | `/api/share/link` | Создать публичную ссылку | - |  
| GET | `/api/share/getAllByToken` | Получить список желаний по ссылке | `token` (query) |  

### Теги  
| POST | `/api/tag/addTag` | Создать тег | `tag` (query)|  
| GET | `/api/tag/getAll` | Получить все теги пользователя | - |
